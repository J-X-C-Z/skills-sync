# Beautiful HTML Templates

Use this repository's template library to create HTML slide decks. At the start of a deck-building task, read `AGENTS.md` for the required workflow, then use `index.json` to select an appropriate template and adapt its HTML and assets. Follow the repository instructions for previewing and delivering the finished deck.
